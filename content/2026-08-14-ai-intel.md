# AI 情报主编候选台｜2026-08-14

> 本批次扫描最近 7 天的 AI 专项信源、官方博客和官方 GitHub。15 条线索中，5 条通过“一手资料可核查”门槛。社会热榜接口尚未配置，因此本文不使用“全网热榜”“热度第一”等表述。

## 今日判断

今天最清晰的主线不是“又有一个更强模型”，而是 Agent 的执行层正在快速标准化：Harness、Plugin、Skill、MCP 和多 Agent 协作开始进入同一套工程语境。模型能力仍重要，但插件是否可移植、权限是否可控、任务是否能持续完成，正在成为新的产品分水岭。

## 1. DeepSeek Harness 开放开发者预览｜2026-08-13｜1 天内

**事实状态：** 已证实；官方仓库已开放，第三方已有首批实测。当前仍是开发者预览版。

**为什么值得做：** DeepSeek 首次把竞争焦点从“模型本身”延伸到 Agent 执行框架，而且选择 MIT 开源和“一切皆插件”的路线。

**核心矛盾：** 插件化带来高度自由，也把兼容性、稳定性和维护成本交给了开发者。

**顺手讲懂的概念：** Agent Harness——给模型接上工具、上下文、权限、任务循环和错误恢复的执行系统。

**可选观点：**

- A｜这是架构范式变化：依据是官方明确采用插件化架构，并把模型、工具和运行能力放在可组合的执行层中。
- B｜现阶段更像高热度开发者实验：依据是官方明确警告版本仍在快速迭代，会出现破坏兼容性的改动。
- C｜DeepSeek 在争夺 Agent 生态入口：依据是 Harness 可承接多模型与多插件，价值不只来自自家模型调用。

**影响谁：** AI 开发者、技术负责人、自建 Agent 工作流的企业，以及提供 Agent 工具或插件的创业团队。

**证据边界：**

- 已证实事实：仓库创建于 8 月 13 日；MIT 许可证；官方描述为 “Everything is a Plugin”；预览期存在破坏性变更风险。
- 第三方观察：已有媒体做了安装和功能体验。
- 本账号判断：9 万级 Star 说明关注度极高，但不能直接证明生产可用性。

**一手信源：** [DeepSeek Harness 官方 GitHub](https://github.com/deepseek-ai/deepseek-harness)

**交叉信源：** [网易：首批安装与功能体验](https://www.163.com/dy/article/L49PQPU4051181RS.html)

## 2. Qwen Code v0.21.11 加入 Agent Plugins 与原生多 Agent 协作｜2026-08-13｜2 天内

**事实状态：** 已证实；官方 Release 已发布，无已知破坏性改动。

**为什么值得做：** 这次不是简单的模型升级，而是把插件扩展与多 Agent 协作推进到终端编程工具的原生能力。

**核心矛盾：** 并行 Agent 能提高吞吐，但任务拆分、只读队友限制和主 Agent 汇总质量决定真实收益。

**顺手讲懂的概念：** 多 Agent 协作——把任务拆给多个权限受限的角色并行处理，再由主角色汇总结论和执行决策。

**可选观点：**

- A｜多 Agent 正从 Demo 进入日常工具：依据是 `/coordinate` 已进入正式 Release，并提供自动结果转发。
- B｜真正难点从“能不能并行”转向“如何协调”：依据是队友只读、主 Agent 汇总，协作协议比模型数量更关键。
- C｜插件标准可能比单一模型更重要：依据是 Agent Plugins v1 允许能力独立于模型版本演进。

**影响谁：** 终端 AI 编程用户、研发团队、独立开发者和内部开发平台负责人。

**证据边界：**

- 已证实事实：支持 Agent Plugins v1；`/coordinate` 支持只读队友；加入 Qwen 3.8 推理控制与会话可观测性更新。
- 第三方观察：插件安装成功不等于所有插件能力都能在当前客户端完整运行。
- 本账号判断：这是一个值得实测的协作能力更新，但不能只用“开了几个 Agent”衡量生产率。

**一手信源：** [Qwen Code v0.21.11 官方 Release](https://github.com/QwenLM/qwen-code/releases/tag/v0.21.11)

**交叉信源：** [兼容性检查清单](https://www.cnblogs.com/indieseek/p/22453103/qwen-code-0-21-11-agent-plugins-v1-compatibility-checklist)

## 3. OpenAI Codex 0.147.0 推进可移植 Agent Plugin｜2026-08-07｜7 天内

**事实状态：** 已证实；官方 Release 已发布。

**为什么值得做：** Codex 同时推进插件可移植性和运行时安全，说明 Agent 生态已经从“功能扩展”走到“权限治理”阶段。

**核心矛盾：** 插件越容易安装和跨项目复用，来源信任、密钥保护和网络权限就越重要。

**顺手讲懂的概念：** Agent Plugin——把 Skill、工具连接、说明和配置打成可以安装和分发的能力包。

**可选观点：**

- A｜Agent Plugin 正在成为新的软件分发单元：依据是 Codex 已支持本地、个人、工作区和远程插件目录。
- B｜安全能力才是这次更新的主角：依据是版本同时加入密钥脱敏、项目显式信任和插件网络隔离。
- C｜Skill、MCP 与 Plugin 正在合流：依据是同一 Release 加入插件能力和 MCP 2026-07-28 协议支持。

**影响谁：** Codex 用户、插件作者、企业安全团队和 AI 开发平台负责人。

**证据边界：**

- 已证实事实：支持可移植 Agent Plugins、分层插件目录、MCP 新协议；加强 Bearer Token 脱敏与插件隔离。
- 第三方观察：行业正在尝试用统一目录结构实现“一次开发，多端运行”。
- 本账号判断：插件市场能否成立，最终取决于权限透明度和跨客户端兼容性，而非插件数量。

**一手信源：** [OpenAI Codex 0.147.0 官方 Release](https://github.com/openai/codex/releases/tag/rust-v0.147.0)

**交叉信源：** [Agent Plugins 标准解读](https://zhuanlan.zhihu.com/p/2070441567324725869)

## 4. Qwen-MM-Plugins 把多模态能力拆成可移植插件｜2026-08-11 至 13｜本周更新

**事实状态：** 官方仓库已证实并持续更新；跨客户端的实际兼容性尚未完成独立验证。

**为什么值得做：** 它尝试把图像、视频、文档和专业软件能力从“某个模型专属功能”变成可装进不同 Agent Harness 的能力模块。

**核心矛盾：** 插件降低模型锁定，但不同客户端对 Skill、MCP 和运行依赖的支持仍不完全一致。

**顺手讲懂的概念：** Skill + MCP——Skill 描述做事方法，MCP 负责把 Agent 接到外部工具和数据。

**可选观点：**

- A｜多模态正在从模型能力变成工具能力：依据是官方定位直接指向 “Make any agent harness multimodal-native”。
- B｜这是一条对抗平台锁定的路线：依据是项目使用 Apache-2.0，并面向多个 Harness 组合能力。
- C｜短期价值在可组合，长期难点在兼容：依据是第三方已指出插件在不同宿主中的能力支持并不等价。

**影响谁：** 内容创作者、设计团队、CAD/3D 用户、AI 产品研发和同时维护多个 Agent 客户端的组织。

**证据边界：**

- 已证实事实：官方仓库由 QwenLM 维护，采用 Apache-2.0，8 月 13 日仍有代码更新。
- 第三方观察：现有插件覆盖图像、视频、PDF、3D 与 CAD 等能力。
- 本账号判断：这类项目的关键指标不是功能清单，而是同一任务在不同 Harness 中能否稳定复现。

## 5. Anthropic 将 Sonnet 5 首发价改为长期价格｜2026-08-10｜4 天内

**事实状态：** 已证实；Anthropic 官方发布页已更新价格说明。

**为什么值得做：** 官方取消原计划 9 月生效的涨价，说明 Agent 模型的竞争正在从能力跑分进一步转向可持续调用成本。

**核心矛盾：** 每 Token 单价下降很明确，但 tokenizer、推理努力档位和 Agent 循环次数共同决定最终账单。

**顺手讲懂的概念：** Token 定价——API 不是按问题次数收费，而是按模型实际读取和生成的文本单位计费。

**可选观点：**

- A｜这是主动参与价格战：依据是官方永久保留首发优惠价，而非按计划恢复标准价。
- B｜便宜不等于总成本下降：依据是官方提醒新版 tokenizer 可能让相同输入映射为约 1.0–1.35 倍 Token。
- C｜模型选型会更精细化：依据是 Sonnet 5 提供不同 effort 档位，团队可以在质量和成本间动态选择。

**影响谁：** API 采购负责人、AI 产品经理、创业团队和需要控制 Agent 月度账单的企业。

**证据边界：**

- 已证实事实：价格为每百万输入 Token 2 美元、输出 10 美元；原计划的 9 月涨价取消。
- 厂商主张：Sonnet 5 在 Agent、工具调用和安全性方面优于前代。
- 本账号判断：评估成本必须使用真实任务回放，不能只比较官网单价。

**一手信源：** [Anthropic：Claude Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5)
