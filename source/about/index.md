# 不追逐每一个热词，只追踪真正改变行业的信号

AI 情报站聚合全球 AI 官网、研究博客、GitHub Release 与中文科技资讯，为内容创作提供经过筛选、溯源和整理的每日素材。

## 情报分层

{% grid c:2 %}

<!-- cell -->
{% box 已证实事实 color:cyan %}
来自官方公告、论文、模型卡、Release 或仓库记录，可以直接核查。
{% endbox %}

<!-- cell -->
{% box 厂商主张 color:blue %}
来自产品方的能力、性能和成本描述，保留来源但不自动视为独立验证。
{% endbox %}

<!-- cell -->
{% box 第三方观察 color:purple %}
来自媒体、开发者或社区的体验与分析，需要与一手资料交叉确认。
{% endbox %}

<!-- cell -->
{% box 本站判断 color:green %}
基于证据给出的趋势判断，明确区分事实和观点，并标注适用边界。
{% endbox %}

{% endgrid %}

## 核心原则

- 优先引用一手信源，而不是转述链条。
- 不用跑分代替真实任务，不用 Star 数代替生产可用性。
- 不把“可能”“计划”“预览版”写成已经发生的事实。
- 重要判断同时说明受影响的人、成立条件与未知风险。

> 如果一条信息无法独立核查，它可以进入观察池，但不会进入“已证实发布”。
